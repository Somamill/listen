# Security policy

This project is a public beta. No audit or anonymity guarantee is claimed.

Do not disclose credentials, cookies, tokens, private library data, or exploitable details in a public issue. Use GitHub’s **Report a vulnerability** / private vulnerability reporting feature when available for this repository. If it is unavailable, open a minimal issue asking for a private reporting channel without including the sensitive details.

Security-relevant fixes should include a small synthetic regression test. Local-token handling, browser-origin validation, credential storage, path validation, remote RPC authentication, and website parsing are particularly important boundaries.
