# listen. native player

Native iOS/iPadOS Operate surfaces, extending the established dot. brand rather than reproducing a web layout. SF typography and symbols, dynamic text, semantic label colors, system tabs/navigation/sheets, native controls and materials. Brand backgrounds and adaptive accent map to `branding/dot/tokens.json`: cream/sage in light, forest/light sage in dark. Library artwork leads; no invented covers, testimonials, metrics, or account state. “Part of dot.” belongs in About.

Library uses an adaptive NavigationSplitView and the native system tab bar. A compact player leads to a focused player sheet. Files import is a system picker; editing/settings use Forms. Goodreads authentication stays in its own website view. Enabled/disabled/loading/failure states describe the actual service state.

Impeccable iOS guidance and Hallmark craft/accessibility principles were applied. HTML lint/render gates do not validate SwiftUI: validation comes from Xcode builds, XCTest and actual simulator screenshots. Native labels, touch targets, light/dark appearance, iPad layout and larger Dynamic Type are reviewed; physical VoiceOver, switch control, hardware route changes and background behavior still need device tests.
