# Contributing to listen.

Bug reports, accessibility fixes, translations, and client-adapter improvements are welcome.

1. Check existing issues and describe the current behavior, expected result, app version, macOS version, and client type/version.
2. Reproduce with synthetic or public metadata. Never upload credentials, cookies, private shelves, service tokens, or personal paths.
3. Add a focused regression test for parser, configuration, or adapter changes.
4. Run the tests and inspect the relevant light and dark screens before proposing UI changes.
5. State what was actually tested. Clearly identify integrations requiring a live external client or website session.

Do not add automatic downloads on sign-in, fabricated ratings, guessed torrent-health numbers, analytics, credential logging, or certificate bypasses. Keep browser/account connections explicit and user-directed.
